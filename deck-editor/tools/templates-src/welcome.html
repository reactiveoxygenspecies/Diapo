01 · Select

Click it,
drag it

  • Click anything on the slide to select it; the panel on the right shows what it is and how it looks
  • Drag to move it; drag a handle to resize it; the round handle above the box rotates it
  • Shift+click adds to the selection; the arrow keys nudge it a pixel
  • Pink lines appear when an edge or a centre lines up with something: let go there

02 · Write

Double-click
any text

  • It edits in place; Esc when you are done
  • Ctrl+B, Ctrl+I, Ctrl+U format the words you selected; the small bar above the text has links, lists and alignment
  • In a list, Enter makes the next item and Tab tucks it under the one above; the List section of the panel turns bullets into numbers
  • With words selected, the panel's font, size and colour change just those words

05 · Pictures

Crop it
by hand

  • Double-click a picture to crop it: drag the picture to move it in its frame, drag the white handles to change what shows, turn the mouse wheel to zoom; Enter when done
  • The Picture section of the panel replaces it with another file in the same frame, flips it and turns it grey
  • Give it alt text there too: a sentence that says what it shows, for people who use a screen reader

06 · Charts

Paste a table,
get a chart

  • Insert › Chart, then type the figures in the Chart section of the panel, or paste cells copied from a spreadsheet
  • Column, bar, line, area, pie or doughnut, one click apart; the colours come from this deck's theme
  • Charts in a PowerPoint file you import come in editable too
Select the chart and change a number in the grid: it redraws as you type. The kind buttons at the top of the Chart section switch it to a line or a pie.
07 · Style

One element,
or the whole deck

The Colour, Text and Box sections of the panel change what is selected. The swatches are this deck's own colours.

Copy style (Ctrl+Alt+C) takes the look of one element; Ctrl+Alt+V puts it on another.

Theme (Ctrl+T) changes the whole deck at once: its colours, fonts and base text styles.

  • Right-click an element for all of this, and to bring it to the front or send it back

12 · Save

Ctrl+S

Sep 26The version before is kept

The file is written where it is. Every save keeps the version before it: Export › Previous versions lists them, opens one beside the deck or brings it back. Edits you have not saved yet are kept as a draft and offered back when you open the deck again.

13 · Precise

The exact
element

  • Ctrl+click picks the exact element under the cursor, not the group it is in; Parent and Inside in the panel walk up and down
  • Alt+drag duplicates; Shift on a corner keeps the proportions, Alt resizes from the centre
  • Lock keeps a background from being dragged by accident; Hide keeps an element in the file but off the slide
  • ? shows every key

14 · Line up

Rulers and
guides

  • Look › Rulers and guides shows rulers in slide pixels; drag a guide out of a ruler, drag it off to remove it
  • Moving and resizing snap to the guides; they are saved with the deck
  • X and Y in the panel place an element to the pixel; with Align to the slide, one element centres on the slide
15 · Every slide

Footers and
sections

  • The print in this deck's four corners is on every slide: click it and change it once. Insert › Footer on every slide adds one to any deck
  • A slide can leave it out: Show the footer and page number here, in the slide's panel
  • A slide's Section field starts a heading in the slide strip, as this tour's three parts do; Name labels its thumbnail

16 · Motion

Further
than fade

  • Transition, in the slide's panel, sets how a slide comes in: this one zoomed. Deck default sets it for every slide
  • Text effect brings text in by letters, by words or typed
  • Morph from links an element to one on the previous slide, whatever they are called, so auto-animate turns one into the other
  • Order, next to Reveal on click, sets which line comes first

19 · Under the hood

It is just
HTML

  • The Code section, at the bottom of the panel, shows the element's HTML and the CSS that styles it; change either, and the element follows
  • A link on any element opens a page when you present; Shrink to fit keeps long text inside its box
  • The badge in the status bar lists problems: a missing picture, a script error
  • The file is plain HTML, with no program or account behind it
