Name the grid: everything on every slide sits on these twelve columns.
Contents

Four principles

1

The grid

A system of columns that every element obeys.

2

Objective type

One grotesque, flush left, ragged right.

3

Asymmetry

Balance without centring.

4

One colour

Red, used as a signal, never as decoration.

1

The grid

Twelve columns of 130 pixels, 30 pixel gutters. The lines are visible on purpose.

1.1

What the grid does

a

Aligns

Every edge shares a line with another edge. Nothing floats.

b

Proportions

Widths are counted in columns: four, six, eight. Never "about a third".

c

Speeds up

With the positions decided, only the content is left to decide.

Double-click to choose an image
2

Objective type

Eight columns for the picture, four for the words. Double-click the frame in the editor to choose a photograph; black and white suits the system.

12

columns

Enough to divide by two, three, four and six. The number is the whole argument for this grid.

The grid system is an aid, not a guarantee.

Josef Müller-Brockmann

Grid Systems in Graphic Design, 1981
