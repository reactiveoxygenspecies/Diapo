Motivation

Sequence models remember everything and pay for it at every step. What if forgetting were part of the model?

Problem statement

  • Attention cost grows with sequence length; long documents become impractical.
  • Existing compression methods are fixed in advance and task-agnostic.
  • We want a memory of bounded size whose contents are chosen by the task.
  • Key question: can a model learn what to forget, not only how much?

Contribution. A differentiable forgetting gate over a fixed-size memory, trained end to end, that matches full attention on three benchmarks at 18% of the memory cost.

The forgetting gate

mt = ft ⊙ mt−1 + (1 − ft) ⊙ φ(xt)(1)

mt
the memory at step t, fixed size k

ft = σ(W xt + U mt−1)
the learned forgetting gate

φ
the write projection of the input

The gate is per slot: the model can keep one slot for a whole document and refresh another every step.

Training procedure

1

Pretrain

Standard next-token objective on the base corpus, memory disabled.

2

Enable memory

Add the gate, k = 64 slots, initialised to keep everything.

3

Sparsity penalty

An L1 term on 1 − f pushes the model to forget what it can.

4

Fine-tune

Task heads trained with the memory frozen, then jointly.
