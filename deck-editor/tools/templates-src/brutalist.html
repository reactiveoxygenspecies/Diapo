01 · Honest materials

A screen is pixels and text

  • Do not pretend the button is a physical object.
  • Do not blur, feather or glow. Edges are edges.
  • System defaults are a valid design decision.
  • If it looks unfinished, that is because it is. Say so.
Note

The borders on this deck are 3px, black, everywhere. That is the whole visual system.
